## Why

The ScrapSAE project currently lacks a central `README.md` file that explains what the project is, how to set it up, and its current state. A comprehensive README is necessary for onboarding new developers, providing quick execution instructions for the development environment, and tracking the status of various modules (e.g., Core, Api, Worker, Desktop, Web).

## What Changes

- Create a `README.md` in the project root.
- Document the project purpose and architecture.
- Document the steps to run the solution locally (e.g. `dotnet run` for API and Worker, environment configuration).
- Detail the current state of all modules:
  - Ready/Stable modules.
  - Modules in development.
  - Incomplete or deprecated modules.

### New Capabilities
- `readme-documentation`: Defines the structure and content for the main project README.

## Impact

- Better onboarding experience.
- Clearer understanding of project structure and module readiness.
